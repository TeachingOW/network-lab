Faster JSON output

Today

Escaping checks one byte at a time, and each item is built from several small appends that may each regrow the buffer.

Proposed

Scan 16 bytes at a time for a character that needs escaping, copy clean runs in one go, and reserve the response size up front.

Why expect a gain

Bulk get is 70% our own code, and its output is almost all escaped values. The reference already scans 16 bytes at a time.

Expected, not measured · json.cpp, handlers.cpp

25 / 30

Every value returned by a get or a bulk get passes through json_escape, which tests each byte for a quote, a backslash or a control character. Almost every byte passes, so the work is a long run of checks that find nothing. The reference tests 16 bytes at once using compiler vector extensions and copies the whole clean run with one memcpy. The second half of this item is reserving the output size before a bulk get starts, since the number of ids is known, so the output buffer does not regrow many times. With the response copy now gone and no gain seen from it, this and the store are the two remaining differences between our bulk get path and the reference’s.
