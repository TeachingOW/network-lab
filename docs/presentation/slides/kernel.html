These are grouped because each is a small saving inside the kernel. Direct descriptors mean accepted sockets live in a table registered with the ring, so each operation skips looking the file up and taking a reference on it. Registering the ring’s own descriptor does the same for io_uring_enter. Setting TCP no-delay once on the listening socket, which accepted sockets inherit, removes a setsockopt call per connection. Zero-copy send avoids copying a response into the kernel, but it only pays above roughly ten kilobytes and gives nothing over loopback, which is how everything here was measured. The idle timeout is not about speed: bulkapi never closes a stalled connection, and the reference closes them after 90 seconds. Direct descriptors need a linked cancel, shutdown and close sequence, which makes the close path more complex.
