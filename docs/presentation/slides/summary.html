29 / 30

The honest scorecard. Of the four implemented changes, removing the per-connection buffer is a clear win, on memory. Multishot receive is a trade-off that depends on connection count. Writing the response once and batching under load changed nothing that could be measured on this machine, although both leave the code no worse. The five open items are ordered by where the evidence points: the store and JSON output are the remaining differences between our bulk get path and the reference’s, which is about 1.4 times cheaper per request there. The last two are about kernel cost and only matter for small single requests.
